# Star Reader fonts

These are original project fonts traced from the approved Star Reader
preview. `StarReader-Title.ttf` carries the soft display alphabet used by
the logo. `StarReader-Math.ttf` carries the rounded numerals and math
operators used on the stars and answer buttons.

`StarReader-source.png` is the clean tracing sheet made from the approved
preview. Run `python3 star-reader/make-font.py` from the repository root to
rebuild both TrueType files from that sheet.
